# Математический PDF → Word

Локальное учебное приложение на Python со Streamlit и русским интерфейсом. Основной режим сохраняет текст редактируемым, а формулы — изображениями; дополнительный режим создаёт формулы Word OMML с резервными изображениями. Для сканов и сложной вёрстки предусмотрен режим целых страниц.

Исходники и приложение находятся в [`mathpdf_docx`](mathpdf_docx/).

- [Дополнительные математические зависимости](mathpdf_docx/MATH_SETUP.md)

- [Анализ тестового PDF](mathpdf_docx/SAMPLE_ANALYSIS.md)
- [ZIP проекта](mathpdf_docx_project.zip)

В проверенном окружении прошли 45 тестов. На пользовательском PDF основной режим обработал все 9 страниц; режим OMML проверен на всех 9 страницах (240 формул Word, 4 явно отмеченных резервных изображения). Исправлены скобки пределов интегралов и преобразование двух сложных формул из пользовательских скриншотов. Формулы и восстановленная структура требуют сверки с оригиналом. Точное воспроизведение вёрстки и стопроцентное распознавание не гарантируются.

Виртуальное окружение, веса моделей и промежуточные рендеры в репозиторий не включены. Модели загружаются отдельно; обработка документов выполняется локально.
