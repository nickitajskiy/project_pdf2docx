# Математический PDF → Word — приложение Tkinter

Настольный учебный проект Python с русским интерфейсом. Открывается отдельное окно; браузер, localhost и сервер не нужны. Преобразует математические PDF в DOCX тремя режимами: редактируемый текст с формулами изображениями, формулы Word OMML, страницы изображениями.

## Запуск после скачивания из GitHub

1. Установите Python 3.11 (64 bit) с Tcl/Tk.
2. Откройте папку `mathpdf_docx`, создайте `.venv` и установите `requirements.txt`.
3. В IDE выберите этот интерпретатор и запустите **`main.py`** из корня репозитория или **`mathpdf_docx/run.py`**.

Точные команды для Windows/macOS и настройка PyCharm/VS Code — в [инструкции](mathpdf_docx/README.md). Базовая установка сразу открывает окно и поддерживает режим страниц. Для редактируемого текста нужны дополнительные математические зависимости, для формул Word также Pandoc. Первое скачивание моделей требует интернета; обработка документов локальная.

- [Установка и запуск](mathpdf_docx/README.md)
- [Математические зависимости](mathpdf_docx/MATH_SETUP.md)
- [Фактические проверки и ограничения](mathpdf_docx/VALIDATION.md)

Окно и конвертер проверены на macOS ARM64. Испытания Windows в этой среде не выполнялись. Точное воспроизведение вёрстки и безошибочность распознавания не гарантируются.
