# Конвертация PDF в DOCX

Курсовой проект - настольное приложение на Python с интерфейсом Tkinter для преобразования PDF файлов в документы Word.

Есть три режима:

- Редактируемый текст с формулами в виде изображений.
- Редактируемые формулы Word с резервным сохранением сложных выражений изображениями.
- Сохранение внешнего вида документа изображениями страниц.

Обработка выполняется локально. Пользователь выбирает PDF, запускает конвертацию и отдельно сохраняет DOCX или отчёты. Отчёт содержит сведения об обработанных страницах, формулах и предупреждениях.

Проект использует pdfplumber, pypdfium2, python-docx, Pix2Text и Pandoc. Основной поддерживаемый тип документов — одноколоночные PDF с текстовым слоем. Точное совпадение вёрстки и безошибочное распознавание формул не гарантируются.
