# Фактически выполненные проверки

17 октября 2026 года. Один исполнитель, без субагентов и обучения моделей.

## Окружение и тесты

macOS 27 ARM64, Python 3.12.14, Tcl/Tk 9.0, Pandoc 3.10.1. Полная проверка после перехода на Tkinter: **65 passed**, без пропусков. Команда из папки `mathpdf_docx`:

```sh
.venv/bin/python -m pytest -q
```

Проверены русский текст, кириллические пути, верхние отметки задач, inline/отдельные формулы, отсутствие дублирования, пределы интегралов, вложенные дроби и структура OMML, узкий резерв из текстового слоя, ошибочные PDF, недоступные модели/Pandoc, ограничения и неизменность исходника.

Настоящие GUI-тесты проверяют окно Tkinter, выбор режимов, фоновую обработку через очередь, ошибки и повторную конвертацию, сохранение DOCX и отчётов, отмену сохранения, запрет закрытия при обработке, сброс старого результата и запуск из IDE независимо от рабочей директории.

В чистом временном окружении установлены только базовые зависимости, без Streamlit и Pix2Text. Создано настоящее окно; выполнены обработка девятистраничного PDF в режиме страниц и сохранение DOCX/отчётов. Структурно подтверждены девять изображений страниц. `pip check` и компиляция исходников прошли.

В песочнице macOS оконные службы недоступны; GUI-тесты выполнялись с предоставленным доступом к графической сессии. Проверка скриншота окна средством UI-автоматизации не выполнена: поиск Python завершился тайм-аутом.

## Математический PDF

Ранее самостоятельно проверен `2023_fan.pdf`: девять страниц A4 с текстовым слоем. SHA-256 исходника: `8e5ee4755377a4e53b9a31cb24cf0eece70c800c5739b4e0ab84bbd65fe23481`.

MFD/MFR действительно запускались локально. Проверялись страницы 1, 2, 5, 8 и полные девятистраничные результаты. После исправлений — 242 математические области: основной режим сохранял 242 вырезки, OMML — 238 формул из OCR и 4 простые записи из текстового слоя. Это не процент точности. Во время последующих проверок форматирования OCR повторно использовался только для вырезок с полностью совпадающими пикселями. При замене GUI весь MFR заново не запускался.

Результаты DOCX ранее рендерились LibreOffice; точная вёрстка не сохраняется. Вне исправленных мест остаются ошибки OCR и особенности отображения отдельных математических записей. Полная посимвольная правильность всех формул не удостоверена. Открытие непосредственно в Microsoft Word не проверялось.

## Границы проверки

Полный запуск Windows, Python 3.11 и macOS Intel в этой среде не выполнялся. Python 3.11 ранее использовался для проверки синтаксиса; это не испытание всех зависимостей. На другом компьютере необходимо установить зависимости и скачать модели, как описано в README.

Созданные при разработке DOCX, отчёты, рендеры и машинные протоколы удалены из поставки при очистке проекта. Приложение создаёт новые результаты в выбранной пользователем папке; тесты создают временные файлы самостоятельно.
