# Фактически выполненные проверки

Дата: 17 октября 2026 года. Один исполнитель, без субагентов и без обучения моделей.

## Окружение

macOS 27.0 ARM64, Python 3.12.14 (предоставленный runtime), Pandoc 3.10.1, локальный LibreOffice из предоставленного runtime. Основные версии пакетов находятся в `output/verification.json` и requirements-файлах. `pip check`: No broken requirements found. `compileall` успешно выполнен Python 3.12 и Python 3.11. Полный runtime-прогон на Python 3.11, Windows и macOS Intel **не выполнялся**.

Начальная установка обнаружила конфликт Optimum 1.24 и Transformers 4.49. Исправлено на Transformers 4.48.3. Загрузчик Pix2Text в исходном пакете зависел от `huggingface-cli` в PATH; проект получает веса через Python API и затем передаёт явные локальные пути. Сетевые ограничения песочницы для установки и скачивания были сняты штатным разрешением. Обе модели успешно скачаны и загружены, обработка затем запускалась с `HF_HUB_OFFLINE=1` и `TRANSFORMERS_OFFLINE=1`.

## Автоматические тесты

Команда: `.venv/bin/python -m pytest -q`.

**21 passed**. Проверены:

- русский редактируемый текст и кириллический путь с пробелами;
- верхний ноль у номера задачи и ошибочное обнаружение номера как формулы;
- формула внутри абзаца, отдельная формула и несколько отдельных формул;
- отсутствие исходных символов заменённой области в тексте синтетического DOCX;
- порядок буквенных пунктов при объединённой рамке детектора;
- шрифтовая рамка корня, ошибочно заходящая на предыдущий текст;
- реальный Pandoc и наличие `m:oMath`, `m:f` в DOCX;
- неподдерживаемая LaTeX-команда и резервные изображения при ошибке OCR / отсутствии Pandoc;
- недоступная модель и работоспособный режим страниц без моделей;
- пустой, повреждённый, зашифрованный PDF и отсутствие текстового слоя;
- ограничения размера и числа страниц;
- обнаружение синтетических колонок с предложением режима внешнего вида;

- запуск русского Streamlit-интерфейса, три режима и отсутствие конвертации при обычном обновлении интерфейса.

Тесты геометрии используют известные рамки синтетического PDF. Это **не** оценка точности модели. Проверка OMML использует настоящий Pandoc. В финальном прогоне пропусков тестов нет.

Streamlit также действительно запущен на `127.0.0.1:8505`. Внутри песочницы открытие порта было запрещено; после штатного разрешения сервер запустился. AppTest не заменяет ручную проверку скачивания через каждый браузер: полный сценарий загрузки через браузер автоматизированно не выполнялся, конвейер конвертации запускался через CLI.

## Пользовательский PDF

Реальное вложение `2023_fan.pdf` найдено в каталоге предпросмотра файлов. PDF открыт самостоятельно; это не предположение из описания пользователя. Исходник не включён в ZIP и не изменён. SHA-256: `8e5ee4755377a4e53b9a31cb24cf0eece70c800c5739b4e0ab84bbd65fe23481`.

Все 9 страниц имеют размер 595.276 × 841.89 pt (A4) и текстовый слой. Сначала отдельно преобразованы и просмотрены страницы **1, 2, 5, 8**, затем выполнен полный основной прогон всех страниц. Проверены изображения корня в кусочной функции, вложенных дробей, последовательностей и подфигурной скобки; проверено наличие отдельных верхних отметок в структуре DOCX. Подробности исходника — `SAMPLE_ANALYSIS.md`.

| Результат | Реальный запуск | Структура DOCX |
|---|---|---|
| `2023_fan_editable.docx` | Все 9 страниц, настоящий MFD, локально | 244 математические области, 244 изображения формул, 0 изображений целых страниц, 30 runs с верхними отметками |
| `2023_fan_pages.docx` | Все 9 страниц без моделей | 9 изображений страниц; текст не редактируется |
| `2023_fan_omml_page5.docx` | Страница 5, настоящие MFD и MFR + Pandoc | 20 областей, 17 элементов OMML, 3 резервных изображения |

Счётчики не являются процентом точности. В основном файле нет строк `(cid:...)` в редактируемом тексте. Количество изображений и математических узлов сверено с отчётами. Полный дополнительный режим OMML на всех девяти страницах не запускался; его проверка ограничена страницей 5 и синтетическими тестами.

Три резервные замены OMML на странице 5 связаны с записью `\\cfrac`, которую установленный Pandoc не преобразовал. Они сохранены исходными изображениями, причины и сырой LaTeX находятся в отчёте. Распознанное `t^5-7t+1=0` было просмотрено; каждый прочий OCR-результат всё равно помечен непроверенным. Математическая правильность всех 17 распознаваний не удостоверена.

## Визуальная проверка

DOCX реально отрендерены LibreOffice обратно в PDF/PNG. Основной файл дал **11 страниц**, режим внешнего вида — **9**, проверочная страница OMML — **1**. Просмотрены обзоры всех страниц и увеличенные фрагменты выбранных страниц. Рендеры — внутренние материалы QA, не включены в ZIP. Открытие файлов непосредственно в Microsoft Word не проверялось.

Основной результат пригоден как редактируемая заготовка, **не является точным воспроизведением**. Вёрстка, разбиение абзацев и положение высоких inline-формул отличаются; некоторые подпункты выровнены ниже базовой линии формулы. У отдельных интегралов остаются одиночные скобки, которые могут повторять часть вырезки. Эти знаки не удаляются молча: в отчёте есть предупреждения для ручной проверки. Полной посимвольной сверки всех формул не выполнено. Не следует считать создание DOCX доказательством правильности математического содержания.

Для результата, который требуется использовать без такой вычитки, выбирайте режим «Сохранить внешний вид»; в нём содержимое сохранено изображениями и не редактируется. Автоматического переключения основного режима в этот режим нет.

## Комплект

ZIP включает исходники, зависимости, инструкцию, тесты, лицензии, три итоговых DOCX, их отчёты и машинный протокол проверки. Веса моделей и виртуальное окружение в ZIP не включены; на этом компьютере они уже установлены в рабочем проекте. На другом компьютере выполните установку из README и подготовку моделей. Платные API, регистрация и отправка PDF в облако не используются.
