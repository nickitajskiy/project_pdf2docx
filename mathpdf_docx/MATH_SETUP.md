# Дополнительные математические зависимости

Базовая установка `requirements.txt` достаточна для режима целых страниц. Основной режим дополнительно требует **MFD** — обнаружение математических областей. Режим OMML дополнительно требует **MFR** — распознавание в LaTeX, а также внешнюю программу **Pandoc**.

```sh
# macOS; Windows: .venv\Scripts\python вместо .venv/bin/python
.venv/bin/python -m pip install -r requirements-math.txt
.venv/bin/python -m mathpdf doctor --load-models
.venv/bin/python -m mathpdf doctor --load-models --recognition
```

Используются Pix2Text 1.1.4, открытые mfd-1.5 / mfr-1.5, ONNX Runtime на CPU. API моделей запускается напрямую; обычный русский текст берётся из PDF и не проходит OCR. Транзитивные зависимости Pix2Text включают PyTorch и другие крупные пакеты, хотя их дополнительные модели таблиц и макета не загружаются.

Первое получение весов требует интернета, но не ключа API, платного аккаунта или отправки документа. Ревизии весов закреплены в `mathpdf/math_engine.py`; установленные версии при проверке записаны в `output/verification.json`. Модели сохраняются в `models`, настройка — `MATHPDF_MODEL_DIR`. ZIP не содержит веса и виртуальное окружение.

После успешной загрузки:

- повторно используется один экземпляр MFD/MFR на процесс, а не на страницу;
- `.complete` в каталоге модели отмечает завершённое получение файлов;
- можно задать `MATHPDF_MFD_PATH` и `MATHPDF_MFR_DIR` для собственных локальных путей;
- `HF_HUB_OFFLINE=1` и `TRANSFORMERS_OFFLINE=1` позволяют проверить автономный запуск;
- отсутствие модели даёт понятную ошибку с предложением режима внешнего вида;
- отсутствие Pandoc даёт изображения формул и предупреждения; OMML в таком результате нет.

Проверенный набор математических пакетов использован на macOS ARM64 / Python 3.12.14. На Windows и Python 3.11 полный прогон в этой среде не выполнялся. Для macOS Intel колёса зафиксированного Torch 2.6 могут отсутствовать; основной набор базового режима и математические модели следует проверять раздельно. Случайный подбор других версий в эту поставку не включён.

Счётчик OMML означает наличие математической разметки, а не математическую правильность. Вся LaTeX-запись OCR остаётся непроверенной до сверки с PDF. Лицензии кода и открытых весов перечислены в `THIRD_PARTY.md`.
